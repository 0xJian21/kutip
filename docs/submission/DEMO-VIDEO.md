Built in `video/` as the `Demo` composition; the video session should set `DEMO_SHOTS` to the durations below (the shot ids in brackets are its clip slots; the clip files are named in `SHOT-LIST.md`). Voice-over to `docs/video/vo-demo.mp3`, captions to `docs/video/captions/demo.srt`.

Voice-over ≈ 290 words, plain and unhurried. Say what the viewer sees; the numbers on screen come from the clips themselves.

Before recording: run the REHEARSAL pre-flight (P1–P15), including `demo-reset` with `--warm` for the Phantom and bot wallets. Record the laptop with `pnpm record` from `video/` (1920×1080) and the phone with iOS screen recording at the same time. Keep the terminal ready with the x402 bot command (dry run first).

## Fallbacks while recording

- Solflare blocks the domain ("Scam site detected"): use Phantom. Do not show the Solflare warning.
- "Blockhash not found" on the phone: tap again; the transaction is rebuilt. Cut the retry.
- No Seen within 10 s: restart the Fly worker (`fly machine restart`), re-record the shot. Never run two workers.
- Command bar slow on the first query (~10 s cold): ask one question off-camera first (REHEARSAL warm-up).
- Only one open cash-out proposal at a time: approve or reject the previous one before recording shot 9.
- Shot 8 needs money in a buyer vault: fund Harbourline and Meridian with 0.20–0.30 USDC each from TEST_BUYER before recording (see PLAN Session 8e proof), or record the sweep right after shot 3 while INV-0154's 1 USDC sits in the Harbourline vault.
